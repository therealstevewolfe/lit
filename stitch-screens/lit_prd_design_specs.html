# Lit - AI Speech-to-Text Desktop Application ## Concept & Vision Lit is a premium, privacy-first speech-to-text desktop application that transforms voice into text with a single keystroke. ## Aesthetic Direction Reference: Linear meets Raycast—dark-mode-first with glass morphism accents, subtle depth through layered surfaces, and micro-animations. ## Color Palette - **Backgrounds**: `--bg-base: #0a0a0b`, `--bg-surface: #111113`, `--bg-elevated: #18181b` - **Accent**: `--accent-primary: #8b5cf6` (Electric Violet) - **Recording**: `--recording: #f43f5e` (Pulsing coral) ## Core Screens to Design 1. **Onboarding**: Welcome screen and model selection. 2. **Main Application (Settings)**: Sidebar navigation with General, Models, and Advanced sections. 3. **Recording Overlay**: Semi-transparent, floating UI with waveform animation. 4. **History**: Past transcriptions list.
